Third: bounded public manuscript and evidence package

This package contains the current standalone manuscript, independent AI review, author evidence checker,
aggregate reports, frozen source documents, and historical review bindings needed
for the public source/claim check. It is not a full empirical replay archive or
a submission-ready release. Both completed LLM calibration versions failed their
selection gates; no threshold-dependent downstream experiment is authorized.

Public verification, from the extracted package root:
  python3 -B manuscript/build_evidence.py

The expanded historical compute arithmetic can also be checked separately:
  python3 -B manuscript/build_compute_history.py --check

This standard-library Python check verifies citations/references, source hashes,
reported counts, the displayed calibration table, source bindings for the separate
independent review and its historical input archive, the bounded author review and
partial compute ledger. It regenerates evidence_20261016.json with a new creation
time. It does not execute inference, rejudge labels, prove theorems, or establish
raw source authenticity. The package build verifies this command in a fresh
temporary extraction without using files elsewhere in the checkout.

Open manuscript/third_working_draft.tex in the native document editor to compile
the standalone source. It uses standard LaTeX packages and an embedded bibliography;
no external images, bibliography or custom conference style are required. The
saved build receipt establishes successful native compilation of its exact source.
Visual layout review remains unverified. No compiled PDF is included or claimed
as visually checked. The working manuscript is not yet in a final ACL template.

Private verification boundaries:
- Recomputing model-pair labels and all weighted cuts from the original selection
  requires the private pinned sample and audited per-pair model observations.
  The public aggregate ledger cannot establish those labels' semantic accuracy.
  local_run/llm_v4_negative_analysis_v1_20261016/analyze.py documents exact inputs.
- Regenerating manuscript/build_review.py's compute and review reports additionally
  requires the original private Mistral launch receipt; only its hash and minimal
  resource fields are released. No global cluster queue or other project data
  belongs in this package.
- Original raw corpora, per-record/account IDs, task labels, model outputs,
  model weights, private orchestration, credentials and third-party paper PDFs
  are excluded. Redistribution rights are not inferred from access or hashes.
- Frozen runtime packages, full environment/model inventories and earlier failed
  attempts remain in the main repository or private workspace as documented.
  This compact package does not supply the environment/assets for full inference
  replay. Do not launch a replacement experiment from the failed configuration.

Attribution evidence, inspected 16 October 2026:
The exact active encoder is intfloat/multilingual-e5-base. Its pinned model card
declares MIT; the pinned Qwen/Qwen2.5-7B-Instruct and
mistralai/Mistral-Nemo-Instruct-2407 cards declare Apache 2.0. Exact revisions,
publisher URLs and retrieved-document hashes appear in

E5 and Mistral repository listings contain no filename with LICENSE or NOTICE;
their card declarations are documented without inventing separate notices.
No model weights or publisher card copies are redistributed in this package.

The Stack Exchange publisher guidance links license applicability to contribution
dates and revision timelines. The frozen parser copies supplied post attributes,
including license/edit metadata when present; it does not reconstruct the full
author history or require every attribution field. Raw owner lexemes are retained
alongside typed owners, and the added site is explicitly declared route context.
Title/body parsing, whitespace normalization and marked-notice removal are
documented transformations. The separate source qualification binds the earlier
tag transport and archive replay. No complete record-level attribution census or
ambiguous-legacy-notice review was performed in this documentary pass. All original
acceptance flags stay unchanged; the raw corpus remains outside the package.

Public source checking, private arithmetic replay of saved observations, and
fresh inference are distinct. Fixed revisions and seeds are identity controls,
not a demonstrated guarantee of bitwise inference across hardware or runtimes.

Scientific limits:
The exact theorem concerns a constructed finite-format family and counts private
information under its access model, not total deployment bytes or natural NLP
utility. The historical proof-review receipt remains source-bound. The separate
18 October independent AI review checks specified arguments and public aggregate
arithmetic, with a follow-up on two manuscript corrections. It is manual review,
not formal verification, exhaustive novelty clearance or private-data authentication.
The author checker verifies review provenance; it does not reproduce the reviewer's
reasoning. The old author reports and pre-correction manuscript are preserved in
the included immutable release_20261016_v4.zip. Its20 original review inputs are
hash-checked, rather than falsely rebinding old reviews to the corrected source.
The public narrative review copy replaces only the local repository-path header
with the GitHub URL. The original report's hash and that transformation are recorded.
The follow-up and arithmetic report are copied without changes.
