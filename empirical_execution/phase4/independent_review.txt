   question-only selection, Civil parent/native-ID alignment, preservation of
   fractional labels and own comment text, missing/community-owner singletons,
   native duplicate links, HTML quotations/code/negation/numbers/author links,

   News title repetition was removed only under the documented exact-line rule.
   These transient metadata/parser fixtures are explicitly software tests, not
   synthetic empirical data or evidence about an original archive.

2. Encoding. Independent chunk tests recovered all 513 content tokens exactly
   once, checked per-chunk E5 prefixes, tested declared capacity refusal, and
   compared content-weighted document pooling with a separate numerical oracle.
   No transformer model was run. Code review checked offline loaders, pinned
   inventory/version/code bindings, all-chunk preservation, explicit tokenizer
   boundary convention, row order and record-local batch scope. Actual-model
   numerical acceptance and resource measurements remain pending.

3. Model selection. All 1,296 combinations of four tied scores from {0,1,2}
   and four binary labels were checked against an independent exact F1 search.
   Zero-positive behavior and strictest ties agreed. Test-label traps confirmed
   that selection refuses a test partition before reading its label fields.
   Unknown-source questions, including zero-target questions, remain present.
   A separate augmented least-squares oracle reproduced all six lambda risks
   on source-group software fixtures (maximum MSE difference
   3.0531133177191805e-16). Input reversal preserved the complete task lock.
   Held-out target construction applies an already frozen vocabulary and does
   not select or modify it. No empirical tag vocabulary or lambda was selected.

4. Requests. Eighty-four checkpoint observations on an explicit graph software
   fixture were recomputed by direct set predicates. Source sampling used only
   genuine-declared sources, while the service universe retained unknown and
   engineering-proxy units. Matched record controls used a single cumulative
   permutation at source raw-count checkpoints with a separate record horizon.
   Distinct intervention counts were independently recomputed. R/S/matched-R
   paths stayed paired when only the graph changed. Exhaustive integer mass
   draws reproduced the PPS first-step mass law, and the one-percent branch
   had its separately constructed ceil(N/100) horizon.

5. Natural ridge artifacts. On the reused Civil100 lexical fixture, an
   independent scalar graph implementation and independent dual-ridge solves
   checked all 80 final checkpoints and all 480 stored method heads. Maximum
   head discrepancy was 8.881784197001252e-16. B-F was checked against its own
   deliberately frozen-selection target, not mislabeled as a correct target.
   This verifies the stored development outputs within numerical tolerance;
   it is not an exact-state or outward-rounding certificate for those heads.

6. Convex mathematics and artifacts. Reviewed the positive Taylor tail bound,
   reciprocal endpoint reversal, monotone squaring, outward dyadic rounding,
   sign-aware gradient accumulation, and lambda-strong-convexity implications.
   The resulting rational bound applies to the exact stored FP32/FP64 inputs
   for single-output mean fractional BCE plus lambda/2 times squared norm.
   It is an optimization-error certificate, not statistical unlearning.
   Independent 180-digit Decimal calculations lay inside 102 rational sigmoid
   enclosures. Empty and half-label symmetric objectives had the expected
   exact bounds. Signed gradient updates included the changed-count penalty
   term. All 25 saved certificates, including the persisted initial head,
   were checked for exact input bindings, independent high-precision gradient
   containment, exact rational bound arithmetic, upward radius, and unchanged
   tolerance. Decimal checks support numerical consistency; the reviewed
   interval derivation, not Decimal agreement, supplies the rigorous guarantee.

7. News and systems. Independent calendar checks covered earliest complete
