Access, persistence and accounting qualification

Landlock is unavailable in this kernel (ENOSYS); the independent probe preserves
that failure. The operative boundary is stricter FD-only seccomp installed with
TSYNC after trusted imports and own-method state loading. Input descriptors are
closed; output descriptors are write-only. Independent existing-path, symlink,
proc-FD, openat2, io_uring, process-access, exec and x32 probes are denied. A second
preexisting thread is also denied access. This supports the reviewed trusted
repair-process contract; it is neither adversarial-native-code security nor
physical erasure. Constructor/evaluator access remains separately permitted.

Version 2 mirrors jointspan's existing upper-triangle Gram representation before
the common decoder; it does not clamp eigenvalues or relax residual thresholds.
The two earlier interface failures and their matching source remain preserved.
Numerical residual/eigenvalue/extended-precision diagnostics are not interval
certificates for original-data ridge targets. Payload allocations, tombstones,
serialization buffers and loaded state are counted within their stated scopes.
OS read-call bytes and explicit output writes do not measure hardware traffic;
metadata reads and some compaction-copy categories remain explicitly unknown.
Mapped ELF inventory is not an authenticated complete dependency environment.
Large original worker snapshots were intentionally not archived; hashes, byte
reports and generation code remain. Continued restore was independently tested
on software states, not by reopening every discarded large service snapshot.
