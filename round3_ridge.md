# Round 3: close the ridge decoder cost without adding a storage assumption

This is a correctly costed **supporting algorithm**, not a novelty claim. CG is classical (Hestenes and Stiefel, 1952), and exact ridge add/delete maintenance is established, including Quan, Wu, and Montana (2026), https://arxiv.org/abs/2603.12977. That paper uses a sum-loss regularizer fixed in its normal equations. Our average-loss normalization must be handled separately.

## Recommended addition to the finalized stack

Keep the canonical coefficient map as the state. Decode ridge from its empty coefficient using deterministic, zero-start conjugate gradients. This requires neither stored rows nor an original-graph cache. Its exact-arithmetic cost depends on the current selected-set rank, and it has a direct residual certificate if stopped early.

Let the current selected set have size n>0 and moments

    M = sum z_v z_v^T,     h = sum z_v y_v,
    A = M + lambda*n*I,   nu = lambda*n.

The target is the minimizer of

    L(theta) = (1/(2n)) sum (z_v^T theta-y_v)^2
               + (lambda/2)||theta||^2.

For n=0 return the specified zero head without invoking CG. The matrix A is SPD and h is in range(M).

### Proposition: exact decoding in the selected rank

Let r=rank(M). Zero-start CG applied to A theta=h returns the exact ridge optimizer in at most r<=min(d,n) iterations in exact arithmetic. An arbitrary warm start needs at most min(d,r+1) iterations. Each iteration uses O(d^2) arithmetic on the stored dense M and O(d) auxiliary vectors. No matrix inverse, eigendecomposition, rank computation, selected-row reconstruction, or retained-payload read is needed.

**Proof.** If u belongs to null(M), then 0=u^T M u=sum (z_v^T u)^2, so z_v^T u=0 for every selected record, and u^T h=0. Thus h belongs to range(M), an A-invariant r-dimensional space. A restricted to that space has at most r distinct eigenvalues. Its inverse on h is a polynomial in A of degree at most r-1 by interpolation at those distinct eigenvalues. Therefore theta*=A^{-1}h belongs to the r-th Krylov space generated by h. CG minimizes the strictly convex quadratic on each such space, so by step r it equals theta*. For an arbitrary start the initial error can additionally have a component in null(M), on which A has the single eigenvalue nu. There are at most r+1 distinct relevant eigenvalues, and at most d altogether. This gives the warm-start bound. The standard CG recurrence uses one dense matrix-vector product and a constant number of vector operations per iteration. QED.

Zero start is the simplest finalized implementation because it is a deterministic function of current moments. No historical head or factorization is kept. Exact warm starts are mathematically safe, but an early-stopped warm-start head can depend on the deletion path; it cannot silently be included in a claim of canonical exact learner state.

### End-to-end cost corollary

For scalar ridge, s=Theta(d^2). At releases t=1,...,T, with selected counts n_t, the indexed coefficient repair followed by zero-start CG has total exact-arithmetic work

    O(Q + Phi_0 + d^2*M_0
      + d^2 * sum_t max(1, min(d,n_t))).

The harmless max(1,...) covers dense moment access and empty cases without special accounting. It can be removed for n_t=0 if the zero-count shortcut reads n directly. A tighter execution-sensitive bound replaces min(d,n_t) by the actual distinct-eigenvalue count seen by h_t or actual CG iterations. Setup/curation, feature extraction, bit complexity, and full state serialization retain their separately stated costs. Space remains the indexed-summary space plus O(d) solver workspace if M is accessed by view (O(d^2) if copied). The CG recurrence computes M p+nu p without storing a second matrix.

The worst case is still O(T*d^3), so this is not a uniform subcubic exact-solve theorem. It closes the accounting gap and yields a genuine exact improvement when curation leaves fewer than d independent selected vectors. Rank is used in the analysis only, not computed by the algorithm.

For c response columns, independent CG has c times the scalar solve bound; dense Cholesky can instead amortize its O(d^3) factorization across the c right-hand sides. Do not claim the scalar cost unchanged for arbitrary c.

## Residual-certified practical version

For any candidate theta, let R=||A theta-h||_2. Then, in exact arithmetic,

    ||theta-theta*||_2 <= R/(lambda*n),
    L(theta)-L(theta*) <= R^2/(2*lambda*n^2).

Indeed theta-theta*=A^{-1}(A theta-h), lambda_min(A)>=lambda*n, and the objective gap is (theta-theta*)^T A (theta-theta*)/(2n). Both bounds use only current moments. If approximate moments or rounding are present, replace R by a rigorously valid bound on the true target residual; a raw floating norm is not a formal numerical certificate.

The spectrum also satisfies

    kappa(A) <= 1 + tr(M)/(lambda*n).

If ||z_v||<=R_z uniformly, then kappa(A)<=1+R_z^2/lambda, independent of corpus size. This can be used directly in the standard CG convergence bound. With kappa_bar=1+tr(M)/(lambda*n)>1, q=(sqrt(kappa_bar)-1)/(sqrt(kappa_bar)+1), zero start gives

    ||A theta_t-h|| <= 2*sqrt(kappa_bar)*q^t*||h||.

To guarantee the parameter certificate reaches epsilon, it suffices to use

    t >= log(2*sqrt(kappa_bar)*||h||/(lambda*n*epsilon))
         / log((sqrt(kappa_bar)+1)/(sqrt(kappa_bar)-1)),

rounded up and truncated below by zero; exact termination provides the competing min(d,n) bound. When h=0, return zero immediately. The special scalar-spectrum case converges in one step. This gives the familiar O(sqrt(kappa_bar)*log(1/epsilon)) iteration form, not a new numerical-analysis result.

A practical deterministic decoder starts at zero, computes an explicit residual for stopping, and uses a dense SPD solve if progress stalls. The fallback costs O(d^3), uses only moments, and its residual is checked too. The supplied float demonstration illustrates this behavior but does not implement interval arithmetic. An early-stopped head is an epsilon-accurate output relative to exact ridge; call that output guarantee approximate even though the statistic state is exact.

## Why ordinary rank-one updates are not the default

With changes DeltaM, Deltah, Deltan,

    A' - A = DeltaM + lambda*Deltan*I.

Even adding one row can make A'-A full rank. Example: d>=2, lambda=1, old selected record (e_1,1), new added record (e_2,1). DeltaM=e_2 e_2^T has rank one but A'-A=e_2 e_2^T+I has rank d. Correct coefficients on e_1 and e_2 are both 1/3. Ignoring the count shift gives both 1/2.

Count-preserving swaps admit an ordinary signed Woodbury route if a low-rank factor of DeltaM is supplied or constructed and its formation is charged. Such a factor can be constructed from the aggregate matrix itself, so retained rows are not intrinsically necessary; the next paragraph gives the exact cost. The canonical aggregate map need not expose changed individual rows, and a dual solve that assumes free access to those rows violates the no-reread contract. A fixed sum-loss regularizer is a valid different learner, including the cited federated work; it should not be silently substituted for the present average-loss learner to obtain a cheaper update.


**Optional aggregate-only low-rank route, not needed in the main stack.** Maintain the current inverse B=A^{-1}, a unique function of current moments in exact arithmetic. Form DeltaA from old/new moments in O(d^2), and factor its rank-r symmetric matrix as U C U^T using exact symmetric elimination with 1-by-1 or 2-by-2 nonsingular pivots. This costs O(d^2 max(1,r)) arithmetic; it does not use retained rows. If the residual has a nonzero diagonal, use that scalar pivot; otherwise a nonzero off-diagonal entry gives an invertible [[0,a],[a,0]] pivot. Each pivot removes one or two dimensions of rank, and its Schur update costs O(d^2) per removed dimension. The nonzero pivot blocks form invertible C. Then

    B' = B - B U (C^{-1}+U^T B U)^{-1} U^T B

costs O(d^2*r+r^3). The inner matrix is nonsingular by the determinant identity because both A and A' are SPD and C is invertible. Decode theta'=B'h' in O(d^2). Initialization costs O(d^3); storing B costs O(d^2); dense rank changes are cubic. This route remains canonical in exact arithmetic because B' is uniquely A'^{-1}. Floating inverse drift needs a reset/residual policy, so the zero-start CG route remains the recommended simple specification. Do not describe a current inverse as free state or this classical Woodbury route as a new theorem.

For a warm start theta_old, the exact new-system residual is

    h' - A' theta_old
      = (h-A theta_old) + Deltah - DeltaM theta_old
        - lambda*Deltan*theta_old.

This gives a cheap old-model adequacy check, but no uniform small-change assertion follows from the raw deletion count: curation can activate many rows.

## Verification performed

`python3 round3_ridge.py --output round3_ridge_check.json`

The script imports the second-pass indexed state implementation. It verified:

- 120 random ordered graphs and 442 releases against independent retained-row moments;
- exact rational CG equality to independent rational Gaussian elimination at every release;
- 407 nonempty exact warm-start checks, including the r+1 iteration bound;
- zero-start iteration counts at most rank(M), checked using rational elimination;
- 320 floating zero/warm-start cases checking the parameter/objective residual inequalities and condition-number bound (no fallback needed in this test collection);
- a five-dimensional normalization counterexample where the Gram change has rank 1 but the normal-equation change has rank 5 and ignoring the count shift causes parameter error 1/6.

Largest floating comparison error was 8.523925255302391e-10 at a 1e-9 target parameter tolerance. This is a finite implementation check, not a mathematical roundoff guarantee. Exact Fraction computations substantiate the algebra and finite-termination implementation; their operation counts are not bit-complexity claims.
