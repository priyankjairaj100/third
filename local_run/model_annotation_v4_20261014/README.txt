V4 is a prospectively specified development follow-up to the failed v3 run.

V3 remains complete and negative: 0/90 joint positives and no selected threshold.
Its coarse bins produced only one sample above 0.95 and none above 0.96.
The v4 change is sampling coverage, not lower quality requirements or new judges.

Use 13 strata with upper cuts .5, .9, .91, .92, .93, .94, .95, .96, .97,
.98, .99, .995. Intervals are right-closed to align with strict threshold
exceedances. Sample min(30,N_h) uniformly in each stratum; retain exact weights.
All old 51 threshold candidates remain. Threshold selection still requires
19/20 weighted panel-positive proportion. Independent uniform validation of
up to 200 ALL above-threshold pairs still requires the exact one-sided 95%
finite-population lower bound to be at least 9/10. No post-validation retuning.

Models, prompts, complete context, deterministic decoding, two-family conservative
labels, unavailable-case denominators, swaps and overlap stability are inherited
unchanged. Identities and seed domains are versioned; canonical orientation
remains label-independent and is preserved across selection and validation.
All newly sampled pairs require fresh model calls, including old exposures.

No human annotation is required or permitted as a hidden dependency. These are
model-defined labels, not verified semantic truth. Original native task-label
utility, exact repair and cost measurements remain separate endpoints.

This package specifies the plan and sampling library. It does not yet implement
or authorize an unreviewed inference path. Activation must bind the successfully
replayed full tail census, code, frame, four fresh seeds, requests and budgets.
Old analysis locks and sealed v3 artifacts are untouched.
