Exact interpretation of the saved field
--------------------------------------
The raw field fresh_retained_graph_equal is retained byte-for-byte. It means
that the harness freshly scored retained inputs and compared its selected
membership and derived canonical logical state to the repaired state at the
remaining horizon. It does NOT assert direct CSR/edge-array identity or
serialized-byte equality. Source polynomial aggregation can merge graph-edge
distinctions. See output_field_interpretation.json, bound to executed source.

Portable replay
---------------
Dependency: Python 3.9 or newer, standard library only. No extra packages,
network, cluster, private inputs or external source checkout are needed.
From this bundle directory, run:

    python3 replay_aggregates.py

Paths are relative to the script, so the complete bundle can be moved. Do not
use Python -O. The script checks the exact manifest inventory, every aggregate
hash, all cut/arm/request metadata, checkpoint receipts, meter identities,
resource views and all-cut summaries. It prints a JSON receipt and writes no
files. Redirect output outside this bundle; extra files inside are rejected.
The manifest verifies integrity, not an external authenticity signature.
Saved equality flags remain execution receipts; portable replay does not
regenerate private embeddings, requests, graph edges or logical states.
