# Natural news/web corpus tier — empirical design audit

Prepared 3 October 2026. This is a proposed protocol based on inspected primary documentation; no corpus download, availability test, corpus statistics audit, or experiment was performed in this pass.

## Decision

Use **CC-News, `vblagoje/cc_news`, as the primary broad news curation audit**, and **the author-provided WCEP-100 extracted release as the mandatory event-aware mechanism replication**. These roles matter: CC-News has authenticated URL/domain fields in the documented schema; WCEP supplies event structure but deliberately enriches related coverage. Use a separately labeled natural-text corpus for the paper's main supervised task. Neither CC-News nor automatically expanded WCEP should be made into a supposedly gold article-classification dataset using inferred labels.

WCEP can become the leading illustrative result, but the paper must display the broad CC-News result alongside it, including a null effect. This prevents a dense event collection from being mistaken for ordinary corpus prevalence. Do not select whichever corpus gives more activation after seeing results.

## What the inspected sources establish

- **CC-News extracted subset:** its maintainer documents 708,241 English articles published January 2017–December 2019, one `train` split, and fields `text`, `title`, `date`, `domain`, `url`, `description`, `image_url`. The text field is described as raw article text; `news-please` performs extraction. Language filtering is documented; missing fields occur. The card contains no gold labels, no detailed deduplication guarantee, and no completed licensing specification. Thus claim “before our semantic curation,” not “untouched or duplicate-complete original crawl.” [CC-News card](https://huggingface.co/datasets/vblagoje/cc_news/blob/main/README.md).
- **WCEP:** the primary paper reports 10,200 event clusters, chronological train/validation/test splits of 8,158/1,020/1,022 events, and roughly 650,000 articles for WCEP-100. It keeps editor-cited articles and caps additional retrieved articles at 100 per event. Additional article memberships are classifier-derived: the paper's manual audit found 52% on-topic, 30% related, 18% unrelated. Event membership is therefore noisy relevance metadata, not a gold duplicate-equivalence relation. [ACL paper](https://aclanthology.org/2020.acl-main.120.pdf).
- **WCEP access:** the authors advertise a pre-extracted gzipped JSONL release and document event summaries, article lists, dates and categories. The repository also contains a slower reconstruction route through Wayback and Common Crawl. The MIT license expressly concerns software/documentation and must not be described as a blanket license for original publisher text. The inspected README does not establish that every article in the extracted archive retains its URL, so that is an ingestion gate for publisher-withdrawal use. [Author repository](https://github.com/complementizer/wcep-mds-dataset), [license](https://github.com/complementizer/wcep-mds-dataset/blob/master/LICENSE).
- **Multi-News:** the authors publish raw releases and a version that removes bad retrievals. It is a useful fallback for naturally related documents, but the standard Hugging Face form mainly gives concatenated documents and summaries; original publisher IDs cannot be assumed. Its dataset agreement is for non-commercial research/education and does not extend publishers' IP rights. Prefer the authors' “Raw data, bad retrievals removed” release, preserve document boundaries, and do not claim it is original web-scale uncensored input. [Author repository](https://github.com/Alex-Fabbri/Multi-News), [usage agreement](https://github.com/Alex-Fabbri/Multi-News/blob/master/LICENSE.txt).
- **AG News:** the common classification version has `text` and four topic labels, with 120,000 training and 7,600 test rows. It is useful as an accessible topic-classification sensitivity dataset. The standard schema does not supply publisher or event IDs. A source inferred from words such as “Reuters” is not authenticated ownership metadata. [Dataset card](https://huggingface.co/datasets/fancyzhx/ag_news/blob/main/README.md).
- **RealNews:** the original repository asks users to submit a form for the full corpus; its reconstruction instructions explicitly include a deduplication stage. Do not make it an essential dependency when immediate frozen replay is required. [Author instructions](https://github.com/rowanz/grover/blob/master/realnews/README.md).
- **FineWeb:** the official card explicitly describes cleaned and deduplicated data. It includes original IDs, URLs, crawl dates and WARC paths; its pipeline applies per-crawl MinHash. It is suitable only for a separately named “additional semantic curation of an already curated release” replication, not raw-input prevalence or reconstruction of documents discarded by FineWeb. [Official card](https://huggingface.co/datasets/HuggingFaceFW/fineweb/blob/main/README.md).
- **C4:** the official TFDS catalog distinguishes `en.noclean`, which disables cleaning including deduplication. That is a real future scale-up option but is approximately 6.21 TiB in its documented form; standard C4 is not the no-dedup version. Avoid making it an initial execution prerequisite. [TFDS C4 catalog](https://www.tensorflow.org/datasets/catalog/c4).

## Freeze protocol (a design choice, not observed facts)

1. Pin repository revision, exact file list, SHA-256 hashes, parser version, and extraction history. Complete this before graph or outcome inspection. Save record IDs as `dataset/revision/file/row`, original URL, original text hash, and source-normalization outputs. IDs must distinguish natural repeated texts; never identify distinct records solely by text hash.
2. Use supplied original text with deterministic Unicode/newline normalization. Do not regenerate, paraphrase, translate, inject copied records, relabel documents, or balance the text distribution. Exclude empty/invalid rows under a frozen rule and retain an exclusion manifest with counts by date/source. Require at least 50 whitespace tokens for article-level audit; report sensitivity retaining all nonempty rows. Avoid corpus-wide exact dedup as silent preprocessing: it changes this study's raw-document target.
3. Keep identical URL/text records as distinct observations in the main raw-release target. Add a explicitly separate sensitivity dataset that collapses repeated retrievals of the same canonical URL **and** identical text. Cross-publisher same-text articles remain separate natural records in both. Save an alias map for the collapsed target and define whether a request removes one raw record or the whole alias group. Never compare targets with different record identity semantics.
4. Source ID is the original URL's registrable domain using a pinned Public Suffix List; publish exact host as a sensitivity. This is operational domain withdrawal, not proof of publisher corporate ownership or copyright. Rows without a parseable URL participate in record deletion and are excluded from domain-withdrawal requests; disclose the fraction. Do not use an `unknown` mega-source. Do not infer sources from text.
5. **CC-News:** use 2017 rows exclusively for curator calibration/development; 2018–2019 rows are the locked deletion-audit corpus. These are release-defined populations, not claims of random sampling from all news. For engineering scales form 25k/100k/full nested samples by stable record-ID hash within the locked corpus. Report dates, domains, and text-length histograms so scaling artifacts are visible. Full-corpus main effects use all available locked rows; samples are for scaling only.
6. **WCEP:** preserve official chronological splits. Fit/calibrate any external partition/curator choices on official train; use official validation for protocol development; reserve official test event clusters for final mechanism audit. Never split articles randomly across these partitions. Preserve every article in the selected event; sampling events is allowed, sampling only high-redundancy articles is not. Treat all official test events as the primary finite population and all repeated requests within an event as dependent.
7. Freeze curatorial embeddings, tokenizer/truncation, normalization, threshold, priority order and any external clustering centroids on the calibration partition. Assign locked documents independently to those fixed centroids. The resulting main counterfactual is the declared fixed curator; do not call frozen corpus-fitted k-means a full retained-data SemDeDup rerun. Separate corpus-fitted refitting experiment compares against its own full oracle.
8. Unit truncation can materially alter semantic similarity. Encode title plus the declared full-body chunking rule with a fixed aggregation, or expose the encoder's truncation rate. No hidden first-512-token definition for an “article-level” claim. Do not use event summaries, category labels, publisher identifiers or target task labels as curation inputs.

## Leakage and target discipline

The broad news tier primarily measures **curation changes and system behavior**, so it does not need a learned event classifier. WCEP event IDs are used for aggregation and blinded annotation sampling, not to create trivially separable classes. A deterministic existing summary serves as a human reference only, not as a record-local training label by automatic inheritance.

For any supervised task layered onto news, define a task with independently valid labels. Freeze train/validation/test by real events and time, then audit cross-boundary exact matches and high lexical-overlap matches. Group repeated URLs and exact text across splits; quarantine overlapping groups from the primary test set before any modeling, record counts, and report the original official test as a sensitivity. Do not use the model outcomes to choose the quarantine rule. A held-out test document must not become a deleted/activated training record.

For the curation audit itself, partitioning by WCEP event is a convenience experiment, not a general semantic curator: it could prevent cross-event suppression by construction. Main graph uses fixed external embedding partitions on the whole locked corpus; event metadata are only evaluation strata. Within-event exact graphs are a validation/interpretability subset with their own declared target.

If approximate neighbor search is needed, it defines an approximate candidate-graph target unless every above-threshold edge is recovered. Use exact pairwise graphs within bounded fixed clusters as the primary guarantee, report pair counts and cluster-size caps, and validate ANN edge recall on a preselected sample. Top-k neighbor lists alone are not certificates of complete blocker sets.

## Natural deletion workloads

Use the exact same manifest for every method and oracle. Stratify without inspecting model loss:

- Uniform random record sequences drawn without replacement.
- Whole-domain withdrawals, sampled uniformly over eligible domains, with results macro-averaged over domains and also weighted by removed records. Show deletion-volume and domain-size strata; source budget one may delete thousands of records.
- Chronological batches (retraction of a fixed date range) with complete raw records, not merely selected examples.
- Selected-record and excluded-record single-deletion strata. Both need exposure denominators.
- Targeted natural blockers: select a naturally occurring unselected record under a seeded rule, delete its actual earlier blockers. This is an adversarial stress workload, explicitly not a prevalence estimate and not a synthetic dataset. Report the record's budget and sampling probability; never present an activation-conditioned average as the default result.

Record and source budgets are different axes. Report both number of deletion entities and raw record fraction removed. With large source withdrawals, do not claim low-record-budget storage guarantees. Use finite cumulative horizons and evaluate sequential releases, not independent fresh deletion requests only.

## Mandatory corpus-level outputs

For every dataset/curator/workload: raw N, selected N, coverage of parseable sources, degree/blocker histogram, rank profile r_k/N, activation-eligible fraction, fraction of requests activating at least one record, additions/removals per raw deleted record, number of sources/events newly represented, retained set symmetric difference, and total bytes including graph, keys, source maps, identifiers, moments, and allocator overhead.

To establish linguistic value, annotate a precommitted stratified sample of activated records and matched retained neighbors from the **natural locked corpora**. Annotators see original text, not method names or losses. Distinguish exact/near-exact copies, same-event new facts, same topic different event, contradictions/corrections, and unrelated false positive. Separately ask whether an activated text supplies a materially different fact relevant to the event summary. Do not equate cosine distance or ROUGE gain with new information. Report both probability-weighted prevalence and a clearly labeled enriched activation case set. If most additions are interchangeable copies, say so and weaken the information-recovery claim.

## Fallback and stop rules

- If CC-News revision cannot be fetched, use a predeclared fixed month of original CC-NEWS WARC files (for example January 2019), exact listed filenames, pinned extraction code and no semantic dedup; publish file hashes and extraction failures. This is a different extraction-defined population, not a silent dataset swap. Common Crawl's original documentation supplies dated WARC file lists and an explicit archive access route: https://commoncrawl.org/blog/news-dataset-available .
- If WCEP's extracted release is inaccessible or missing URLs, retain WCEP for record-level event analysis if texts are usable; run source deletion on CC-News only. Multi-News raw corrected release is the fallback natural event-group dataset, with no publisher claims absent verified metadata. Never synthesize missing records or reconstruct them through an LLM.
- If neither news corpus has meaningful activation at acceptable deduplication quality, report that falsifying result; do not loosen thresholds on the locked test to manufacture a phenomenon. A pilot can adjust only calibration choices before the protocol is frozen.
- Do not advertise a downloadable raw-text redistribution package based on a software license. Release scripts, pinned manifests, request lists, dataset hashes, permitted derived statistics and annotations with provenance; follow each source's access/usage conditions. Raw-text access should remain through the original source where necessary.
